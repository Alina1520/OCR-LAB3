# Лабораторна робота 3

Нарижна А.О., ПЗ-47. Варіант 9, SEED = 9450.

## Файли

- `lab3_fixed.ipynb` — основний локальний ноутбук: дані, Tesseract, VLM для власних фото, метрики, графіки та аналіз пунктів 1–16.
- `lab3_colab.ipynb` — VLM для синтетичних зображень та IAM у Colab.
- `requirements.txt` — бібліотеки для локального ядра Jupyter.
- `source.txt`, `corpus.txt` — початковий український текст і рядки корпусу.
- `data/` — синтетичні PNG та еталон, `iam/`, PNG-копії власних фото `my_photos/` і додатковий дослід `ci_extension160/`.
- `my_photos/` — чотири оригінали HEIC з EXIF та однойменні транскрипції TXT.
- `results/` — основні 768 відповідей, метрики, абляція, метадані, JSON власних результатів та таблиці аналізу.
- `figures/` — використані графіки.

## Виконання

Відкрийте локальний ноутбук із цієї папки. Перша комірка `%pip install -r requirements.txt` встановлює бібліотеки в активне ядро. Tesseract з ukr та eng встановлений окремо; шлях у коді — `D:\Tesseract-OCR\tesseract.exe`.

Блоки підготовки даних та абляції потрібні для відтворення експериментів. Для перегляду готових результатів запускайте аналіз пунктів 11–16: повторне розпізнавання не потрібне. Пункт 10 пропускає вже збережені відповіді.

Для VLM у Colab потрібні Ollama з qwen2.5vl:3b, GPU та папка `/content/data` із синтетичними зображеннями й IAM. Власні фото туди не завантажуються. CSV із Colab збережіть локально як `results/recognition_results_colab.csv`; блок локальної VLM імпортує відповіді до `results/recognition_results.csv`.

Додатковий дослід на 160 рядках зберігається окремо в `data/ci_extension160` і не входить до основних 768 результатів. Оригінальний еталон та його SHA-256 збережено без зміни.
